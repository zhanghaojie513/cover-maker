# 参考封面彻底拆解档案

> 2026-10-22 逐张裁切核对。样本：**4 张高清单封面 + 6 张拼图（裁出 36 张，去重后约 30 张独立封面）**。
> 本文档是**事实记录**；`style-dna.md` 是提炼后的规范，`prompt-craft.md` 是落地配方。

---

## 一、最大的一个发现：标题是扁平的，不是 3D 金属字

逐张放大核对 30+ 封面后，这条最颠覆之前认知：

| | 参考实际 | 我之前做的 |
|---|---|---|
| 汉字标题 | **纯色扁平特粗字**（亮黄/奶白/白），无挤出、无金属渐变，最多一层淡阴影 | 厚重 3D 金属挤出字，像铜字招牌 |
| 数字 | **两种都有**：扁平平涂（多数）/ 3D 金（少数，如「8种」「5种」「10」） | 一律 3D |
| 量词（个/种） | 跟着数字走——数字扁平则量词扁平，数字 3D 则量词常也 3D | 一律金 3D |

**证据**：
- 「6个App和小程序 高级审美UI布局」：数字「6」纯黄扁平，汉字奶白扁平
- 「8种 App和小程序 高级卡片按钮交互」：数字「8」和「种」都是 3D 金，下面汉字全扁平白
- 「术语Skill 提升AI审美8种」：全是扁平，靠黄马克笔刷底和字重压场
- 「6个高级交互 让AI做的App和小程序更精致」：荧光黄绿扁平字，无任何金色

**正确 prompt 写法**：
```
extra bold flat Chinese type in cream white and bright yellow, no 3D extrusion
```
数字要 3D 时单独修饰：
```
a glossy 3D gold number inline with the first line
```

## 二、五种排版母版

### 母版 A · 上题下叠压（最高频）
```
[顶部双胶囊 居中]
[数字+标题 2–3 行，扁平特粗，行距为零]
[手写小注 / 马克笔衬底]
────────────────
[素材：多张完整界面叠压，四边出血，前大后小]
```
占比：标题 35–40%，素材 55–60%。
样本：S1「6个App」、S4「2个图标库」、D4「6种弹窗」

### 母版 B · 左文右竖排瀑布（次高频）
```
[双胶囊 左上]
[数字+标题 竖排 3–4 行，左对齐]      [右侧：双列竖排卡片
                                      明暗交替，编号 01–08]
[术语式副标题：错位·留白·非对称]
[底部：图标条 / 点赞]
```
占比：文字区 40–45%，素材 55–60%。
样本：E2「5种高级审美布局」、S3「10个高级交互」、B5「8种提示动效」

### 母版 C · 上题下编号网格（组件清单专用）
```
[双胶囊]
[数字+标题]
[一行说明]
────────────────
[2×5 或 2×4 编号网格，每格一个控件 + 中文名]
```
样本：S2/S5「10个交互组件」（01–10 编号）、A4「6种Web动效」（01–06 + 英文名）、B3「8个动效」

### 母版 D · 满版三连（工作流款）
```
[大字标题，马克笔刷底] [右上箭头]
[流程关键词条：脚本 / 分镜 / 剪辑]
────────────────
[3 台手机并排，完整界面，轻微倾斜]
```
样本：F2「产品短片AI工作流」、B3「APP开发工作流」、B6「豆包Agent」

### 母版 E · 亮底杂志式（少数但亮眼）
```
[浅米白/奶油背景！]
[黑字 + 橙红强调]
[素材：深色网页悬浮于浅底，带 01/08 页码]
```
样本：C5/D2「用UI设计Skill 让AI拥有高级审美」

### 母版 F · 教程五段式（信息最完整）
```
[标题 3 行]
[说明条：从配色到布局，再到整体效果]
[5 个步骤图标 + 文字]
[2×4 面板网格]
[底部：标签 + 点赞]
```
样本：F1「8种高级审美Dashboard」、B8「5种高级交互」

## 三、标题系统详解

### 3.1 排布：咬合式
- 数字与首行汉字**同一基线**（inline）
- 多行之间**行距近乎为零**
- 左右边距仅 4–6%，标题几乎撑满宽度
- **不要写 `filling`**（会让模型把标题做到 55%+），写 `occupying the upper 40 percent`

### 3.2 分色规则（按角色）
| 行 | 颜色 |
|---|---|
| 数字 | 亮黄 / 3D 金 |
| 数量+对象行 | 奶白 |
| 品质词（高级/高级审美） | 白 或 黄 |
| 主题词（UI布局/交互组件/Dashboard） | 亮黄（有时青色渐变） |
| 承诺行（一次学会） | 白 + 两侧细横线 |

### 3.3 马克笔刷底（三个样本反复出现）
标题某几个字**压在一条手绘感色块上**：
- 「术语」压黄色马克笔刷（C1/C3/C6）
- 「AI工作流」压黄刷 + 速度线（F2）
- 「一次教会你」压黄刷（A4）
- 「喝杯咖啡，App UI就改完了」椭圆黄刷（B6）

prompt: `on a rough hand-painted yellow marker swash`

### 3.4 副标题的四种手法
1. **术语串**：「错位 · 留白 · 非对称」「布局 × 配色 × 图表 × 信息层级」
2. **流程条**：「需求 → 设计稿 → 代码」「脚本 / 分镜 / 剪辑」
3. **手写批注**：「每种都配AI描述词」（斜置 + 马克笔）
4. **承诺句**：「一次教会你」「告别模板感」

### 3.5 装饰元素
- 黄色箭头（右上斜指，F2/B3/B2）
- 手写英文斜插（A5 的"Interaction"）
- 竖排大写英文小字（S2 右上"SIMPLE COMPONENTS / GREATER POSSIBILITIES"）
- 速度线 / 爆炸线（标题旁 2–3 道）

## 四、素材系统（最大差距所在）

### 4.1 必须是「完整可辨识的 App 界面」

参考里每张手机屏都是**完整 App**：顶部栏 + 内容区 + 底部 Tab 栏，能说出是什么 App。

| 样本 | 素材内容（可辨识） |
|---|---|
| S1「6个App」 | 民宿预订(ONSEN)、房车租赁(NOMAD)、旅行攻略(里斯本)、阅读(今天读什么)、番茄钟(FOCUS ROOM 25:00)、习惯打卡(Habit Wall 8/11) |
| B1「5个动效」 | 5 个音乐播放器界面（含 128 音量值） |
| D4「6种弹窗」 | 每日打卡格、猫咪插画卡、专注计时环(128)、PASS 卡、SESSION COMPLETE 弹窗 |
| F2「AI工作流」 | 日历、专注计时、情绪记录 |

**返修样本的 v8/v9/v10 全是抽象色块和曲线，没有一个是可辨识 App** —— 这是"不像参考"的根本原因。

**正确做法**：点名具体 App 类型
```
six distinct mobile app screens — a travel guide, a van rental list, a focus
timer, a habit tracker, a reading app, a settings page — each with its own top
bar and bottom tab bar
```

### 4.2 底色完全自由（不是黑系）

核对到的卡片底色：**米白、纯白、奶油、浅紫、深紫、墨绿、浅绿、深青、深蓝、奶黄、荧光黄绿、橙、宝蓝、黑**。

**规律**：黑金只负责框架（背景/标题/数字/光弧/标签），素材内部是**彩色自由世界**。

极端案例：
- 「6个高级交互」(C4/D1)：荧光黄绿 + 白底，**完全无黑无金**
- 「用UI设计Skill」(C5/D2)：浅米白背景 + 黑字 + 橙红，**整张是亮色**
- 「6种弹窗」(D4)：深黑背景 + 8 张全亮色卡片

### 4.3 排布：溢满 + 叠压 + 景深
- 四边几乎无留白，最外层被切
- 一张压一张，前清晰大、后模糊小
- 例外：编号网格款整齐 2×5，但同样底部出血

### 4.4 五种组织形态
| 形态 | 用于 | 样本 |
|---|---|---|
| 叠压堆叠 | 风格展示 | S1、D4 |
| 竖排双列瀑布 | 清单展示 | E2、S3、B5 |
| 编号网格 2×5 | 组件清单 | S2、A4、B3 |
| 三连并排 | 工作流 | F2、B3 |
| 单主角 + 磁贴环绕 | 图标/单功能 | S4、C4 |

## 五、内容设计

### 5.1 标题公式
```
[数字] [量词] [对象] [品质形容词] [主题词] (+ 承诺行)
  6     个    App和小程序   高级审美   UI布局    一次教会你
  10    个    App和小程序   高级       交互组件   —
  8     种    高级审美      Dashboard  —         一次教会你！
```

### 5.2 胶囊标签（顶部双枚，最稳定）
| 左（金底黑字/黄底黑字） | 右（描边） |
|---|---|
| 设计师·交互指南 | 交互组件 |
| AI × VibeCoding | App / 小程序 |
| AI · 交互设计 | App + 小程序 |
| 一套工作流 | UI SKILL |
| 术语Skill | 01/08 |

**内容规律**：左 = 栏目/身份，右 = 对象/品类。**不是标题复读**。

### 5.3 点赞数（发布平台元素，不是封面设计）
样本数值：176 / 303 / 455 / 467 / 469 / 473 / 533 / 545 / 547 / 593 / 630 / 841 / 891 / 942 / 951 / 1132 / 1312 / 1409 / 1846 / 1928 / 2758 / 3035 / 3603 / 4794 / 5088 / 6881 / 19777

**左下角，白色心形 + 数字**。这是平台 UI 叠加，**直出不要画**。

### 5.4 干货感的四个来源
1. 数字明确（4/5/6/8/10，绝不写"多个"）
2. 素材可数（说 6 个就真放 6 个，能数）
3. 承诺具体（一次教会你 / 每种都配AI描述词）
4. 术语密度（错位·留白·非对称）

## 六、差距对照表（返修 v10 vs 参考）

| 维度 | 参考 | v10 | 修法 |
|---|---|---|---|
| 标题字效 | 扁平特粗 | 厚重 3D 金属 | `flat extra bold, no 3D extrusion` |
| 标题排布 | 数字 inline、行距为零 | 数字独立块、行间留空 | `number inline, lines packed tight` |
| 素材形态 | 完整可辨识 App | 抽象色块曲线 | 点名 App 类型 |
| 素材留白 | 四边出血 | 缩在中间 | `cropped by edges` |
| 素材景深 | 前大后小前清后糊 | 均匀等大 | `front sharp, back blurred` |
| 副标题 | 术语串/流程条/手写 | 单一承诺行 | 加「A·B·C」术语串 |
| 马克笔 | 标题压手绘色块 | 无 | `on a yellow marker swash` |
| 装饰 | 箭头/速度线/手写英文 | 无 | 加 `yellow arrow` 等 |
