# Layouts — 构图锚点库（prompt 语言，无 HTML）

**本文档是 prompt 的构图锚点来源，不是布局说明书。** 每个骨架给你 1–2 句英文构图句（直接填进 `prompt-craft.md` §1 主模板的构图槽）加变化轴。这里没有 CSS、没有像素、没有定位——文字修复模式的 HTML 摆位用 `assets/composite.html` 现成结构，不需要本文档。

**为什么是锚点不是模板**：用户要求"风格类似但不固定死这四张图的模版"。做法：骨架家族（7 个）× 变化轴（每骨架 3–4 条）。同一骨架连续两次使用必须在 ≥2 条变化轴上拉开差异；骨架之间可杂交（以一个为主定分区，另一个只出局部元素）。

选择依据是**内容类型**，不是审美偏好：

| 内容类型 | 骨架 |
|---|---|
| 列表干货（"N 个 X"） | ① 左文右堆 / ② 居中扇形 |
| 教程指南 | ③ 斜切动势 / ④ 满版大数字 |
| 工具/组件合集 | ⑤ 标签级联 / ① |
| 榜单、评测 | ⑥ 徽章拼贴 |
| 纯主张、宣言（无数字） | ④ 无数字变体 / ③ |
| **教学干货（"N 个 X Dashboard/App"，截图陈列主体）** | ⑦ 上题下图陈列 |

---

## ① 左文右堆

**构图句**（填主模板构图槽）：`Title block on the left, {素材} floating on the right side`
**画面**：标题、数字、英文小注组成左侧纵队；右侧素材堆（卡片/样机）悬浮、互相叠压。
**变化轴**：数字占比（小注级 / 巨型主导）；标题 1–3 行；右侧素材是卡片还是手机样机；主光晕跟数字还是跟最大素材。

## ② 居中扇形

**构图句**：`Title centered in the upper half, {素材} fanned across the bottom, slightly cropped by the frame edge`
**画面**：标题区居中，下半区素材呈扇形/弧形展开，底部出血裁切。
**变化轴**：素材数量 3–6；扇形弧度（平铺 / 半弧 / 阶梯下沉）；数字嵌在标题行内还是独立巨字；批注压在标题右下还是左上。

## ③ 斜切动势

**构图句**：`Diagonal dynamic composition, title sweeping across at a slight angle`
**画面**：标题块整体倾斜或行间错位，素材沿同向斜率级联。动感最强，适合教程/进阶。
**变化轴**：倾斜角度；行错位幅度；素材顺斜排还是反向制衡；金白比例（3白1金 ↔ 2金2白）。

## ④ 满版大数字

**构图句**：`A giant 3D polished gold number "{数字}" filling half the frame, title beside it`
**画面**：数字占画面一半以上（可出血到边），标题小一号压在数字上或旁。无数字变体：两字巨词主张占半版。
**变化轴**：数字位置（左上/右下/中心出血）；标题压字方式（骑线/旁注/竖排）；素材量（0–3 小件点缀）。

## ⑤ 标签级联

**构图句**：`Title upper left, {素材} cascading from top right to bottom left in an S curve`
**画面**：顶部 1–2 个胶囊标签，标题区偏左，素材从右上到左下 S 形级联（大→小→虚化远景）。信息量最大，适合工具合集。
**变化轴**：标签数量与排布（单行/错位两行）；级联方向（S 形/单侧落）；素材带序号感（金圈数字）与否。

## ⑥ 徽章拼贴

**构图句**：`Title on the left, circular gold-framed badges with icons scattered over the right, some overlapping the title edge`
**画面**：素材是徽章/图标墙（金描边圆徽、星芒、丝带），自由散布、局部压标题边缘，"成就/收录"感。适合榜单、精选集。
**变化轴**：徽章数量 4–9；有无 1 个超大主徽章；环形英文小注有无；散布密度。

## ⑦ 上题下图陈列

**构图句**：`A huge extra bold title block filling the upper half, the first line with a giant glossy 3D gold number inline beside the Chinese words, {素材} filling the lower half, one cropped by the frame edge`
**画面**：AI 教学干货封面款（"6个高级审美Dashboard"）：上半区巨型金数字**与首行汉字同一基线**（inline，不是悬浮的大数字）+ 金白双色多行大标题 + 顶部双胶囊；下半区亮面真实 UI 或深色玻璃组件阵列铺满并底部出血。素材槽用 `prompt-craft.md` §1.5 的对应派系句。
**⚠️ 数字必须 inline**：写成 `with a giant 3D gold number beside the title` 会让数字变成独立悬浮的左上角巨物（那是骨架④ 的气质）。参考里的数字紧贴首行、和汉字咬合，读起来是"3家订阅"一个整体。
**分区基准**（9 张参考视觉估算）：胶囊 4–9% / 标题区 35–45% / 素材区 50–60%。标题要比骨架①② 大得多，**字小 + 留白多 = 普通配图**，这是干货封面和设计海报的分界。
**变化轴**：阵列模式（阶梯下沉 / 扇形弧线·中间高两侧低 / 网格微倾 / 图标磁贴弧散 / 底部编号网格条）；素材形态（整屏截图 / 图标磁贴 / 组件卡片）；数字占比（骑标题 / 半版巨字 / 缩到 0.6 让位超大主题词）；标题对齐（居中 / 左对齐纵队）；胶囊标签（无 / 单枚居中 / 双枚并排·一金底一描边）；出血方向（数字左出血 / 素材底出血）；底部收口（圆弧光带 / 地面镜面反光 / 无）；金色光效拖尾有无。

> 右侧纵贯的双列卡片级联**不属于本骨架**——那种"左标题 + 右侧整列卡片"是骨架①③ 的杂交款，素材句见 `prompt-craft.md` §1.5 对应行。

## 防重复与日志

- **先读 `.cover/log.json`**（本 skill 自己的出稿记忆，首次出稿则没有该文件）：最近一条若用的是同一骨架，本次必须换骨架；骨架不同则与最近 3 条里任一条至少差 2 条变化轴。
- 杂交合法且鼓励：`③斜切 + ②扇形`、`④大数字 + ⑥徽章` 都是有效组合。
- 所有骨架共享的风格锁（色板、字体、质感、卡片语言、无整齐网格）见 `style-dna.md`，骨架只定构图动势。

### `.cover/log.json` 格式

```json
[
  {"date":"2026-10-21","skeleton":"5","axes":["cascade-S","badge-on","cards-3"],"topic":"figma-plugins"},
  {"date":"2026-10-20","skeleton":"1","axes":["num-320","cards-right","title-2row"],"topic":"interaction-components"}
]
```

字段：`date` 出稿日期 · `skeleton` 骨架编号（1–7）· `axes` 本次用到的变化轴标签（自拟但同一骨架下保持同一套词汇，便于比对）· `topic` 主题关键词。数组 prepend 最新一条在前，保留最近 10 条。文件放在**当前项目根目录**的 `.cover/log.json`；目录不存在就创建。
